# Ramanujan evidence boundary

Ramanujan was a non-authorizing research scaffold. Phase II retires its
active Python kingdom while retaining the evidence needed to audit its claims:
the signed boundary and contracts, runtime/audit records, pinned container
replay material, Lean capsule, corpora, fixtures, and the final guarded
command.

The live verification homes are now:

- `tools/verify/ramanujan_layout.py` — resolves current and historical evidence
  paths.
- `tools/verify/ramanujan_boundary.py` — reads the non-authorizing completion
  boundary.
- `tools/verify/restream_guard.py` — validates bounded storage, ownership, and
  fail-closed launch gates.
- `tools/verify/proof/` — exact arithmetic, SymPy, Lean availability, proof
  trajectories, and independent verifier routing.

The GLM range operator and its tests import those canonical verification
modules directly. No production path should import a `ramanujan` Python
package or treat the retained evidence as runtime authority.
