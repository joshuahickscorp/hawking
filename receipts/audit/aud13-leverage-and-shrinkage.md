## Classification rules used

Every item is exactly one of: **IRREDUCIBLE · SUBSUMED · MERGEABLE · DERIVED · RECURRING · HARDWARE_CONTINGENT · OBSOLETE**.

- **SUBSUMED / OBSOLETE** require a named replacing capability **and** a call of that symbol. Only two items qualify: `C03` → `run_runtime_archaeology` at `hcli/agentos_cli.py:702`; `workspace/docs/reference/ROADMAP.md` → canonical H-ROADMAP (parser `DEFAULT_ROADMAP`).
- SING/LAT/F/platform are **MERGEABLE**, not SUBSUMED. Prose is not a caller.
- U50 rungs and Theia MICRO–RESEARCH are **HARDWARE_CONTINGENT** (also mergeable into one ladder / derived from T0 — extra fields in JSON, single class as required).
- P01/P18/C01/C08/C20/C36/C40 are **RECURRING**.
- `C34` (plan scoring) is **DERIVED** from `C33` once measurements exist; `score_physical_candidates` still cannot promote.

Capability states use the required vocabulary (ABSENT … STALE_ROADMAP_TEXT). A passing unit test is not INTEGRATED. A simulation is not PHYSICALLY_MEASURED. Gene I-A SCAFFOLDED is not I-A 80%.
